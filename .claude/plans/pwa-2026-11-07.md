## How it works today (checked 07-11-26)

- No manifest or service worker existed.
- The admin app is Blazor Server, so it needs the server online. There's no offline app, only an
  offline page.
- The server has no model (ServerAi None). The web's SentinelGPT (AssistantPanel, the agent and
  its tools) already reaches the Mac's Ollama through SentinelAgentRelay, so a phone gets
  SentinelGPT whenever the Mac app is open.
- Mac-only: Touch ID sign-in and "Approve on my Mac" (TouchIdKeyStore, SignInApprovalRelay), Mac
  notifications, voice notes, Capture, the offline quick-note outbox, attaching a workspace folder,
  and Deep Analysis (DeepAnalysisAdvisor runs in the Mac app).

       X-GWS-Push.

     - Tests: `WebPushTests` (decrypts the push as RFC 8291, and wires the real container),
       plus the sw.js handlers in `PwaTests`.
   - Passkeys already existed (17-10-26, `/auth/passkey/*`, `/admin/account/touch-id`). The
     bug: an iPhone Home Screen app has no "Safari/" in its user agent, so `isEmbeddedWebKit()`

     sentinel-workspace.js. Wording names Face ID, Touch ID or fingerprint by device
